    How this editor works

    1. Pick a page in the column on the left (Home, Portfolio, Galleries…). The preview on the right is your real site.
    2. Click any text in the preview to type on it directly. Hover a card to hide or remove it.
    3. Pictures: press Add pictures, then Arrange pictures to drag, select, set a cover or delete.
    4. Galleries: each one can be hidden, locked with a PIN, and allow downloads.
    5. Style and Layout: change fonts, colours, logo, and choose a header and footer look.
    6. Publish changes sends everything to GitHub. You will see each step, and your site updates in about a minute. (Shortcut: Cmd/Ctrl + S)
